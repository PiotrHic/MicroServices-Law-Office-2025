# ⚖️ MicroServices Law Office 2025

> A modern **microservices-based law office system** built to demonstrate real-world backend architecture, observability, resilience patterns, and a lightweight frontend.

This project is designed as a **hands-on showcase** of how production-grade microservices are built, tested, monitored, and integrated — all in one cohesive system.

---

## ✨ Why This Project?

Most demo projects stop at "it works".

**MicroServices Law Office 2025** goes further:
- ✅ Clean architecture
- ✅ Real microservices patterns
- ✅ Observability & resilience
- ✅ Automated testing
- ✅ Containerized & ready to run

Perfect for:
- 📚 Learning microservices

- 🚀 Showcasing backend + DevOps skills

## 🚀 Key Functionalities

### 🧩 Core Architecture
- REST APIs with full **CRUD** support
- **Microservices Architecture**
- **API Gateway** for centralized routing
- **Basic Frontend** built with Vite

### 🧪 Testing & Quality
- Integration testing with **Testcontainers**
- Unit testing using **JUnit 5** & **Mockito**
- API testing via **REST Assured**
- Build automation with **Maven**

### 📊 Observability & Monitoring
- Centralized **Logging**
- **Spring Actuator** for health & metrics
- **Micrometer Tracing**
- Distributed tracing with **Zipkin**
- Metrics collection using **Prometheus**
- Dashboards powered by **Grafana**

### 🛡️ Resilience & Stability
- **Circuit Breaker**, **Retry**, and **Rate Limiter** patterns
- Implemented with **Resilience4j**
- Global **Exception Handling**
- Request **Validation**

### 📄 Documentation & API
- Auto-generated API documentation via **OpenAPI**
- HTTP request tracing with **HTTPExchange**

### 🐳 Infrastructure
- **Docker Compose** for local orchestration
- MongoDB for persistence
- Very basic security layer (intentionally minimal)

## ▶️ Getting Started

```bash
# Clone the repository
git clone https://github.com/PiotrHic/MicroServices-Law-Office-2025.git

# Start the system with Docker Compose
docker-compose up --build
```

Once running, you can:
- Access APIs through the **API Gateway**
- View metrics in **Grafana**
- Inspect traces in **Zipkin**
- Explore auto-generated **OpenAPI docs**
